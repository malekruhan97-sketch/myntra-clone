# 🛍️ Myntra Clone

A responsive fashion e-commerce website inspired by Myntra, built using **HTML, CSS and JavaScript**.

🔗 **Live Demo:** https://myntra-clone-kappa-eosin.vercel.app/

## 📌 About The Project

This project recreates the look and feel of Myntra, one of India's most popular fashion platforms. I built it to practice layout design, responsive web development and DOM manipulation using vanilla JavaScript.

## ✨ Features

- Responsive design 
- Navigation bar with category menus
- Product cards with image, name, price and discount
- Interactive UI using JavaScript
- Clean and organized folder structure
- Add your own: cart

## 🛠️ Tech Stack

| Technology | Usage |
|------------|-------|
| HTML5 | Structure of the pages |
| CSS3 | Styling, Flexbox, Grid, responsiveness |
| JavaScript | Interactivity and DOM manipulation |

## 🚀 How To Run Locally

1. Clone the repository
   ```bash
   git clone https://github.com/malekruhan97-sketch/myntra-clone.git
   ```
2. Open the project folder
   ```bash
   cd myntra-clone
   ```
3. Open `index.html` in your browser (or use the Live Server extension in VS Code).
